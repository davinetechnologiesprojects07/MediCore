# MediCore — HTML/CSS/JS Frontend

MediCore is a professional healthcare operations UI prototype based on the supplied MediCore capstone specification.

## Run

No build tool is required.

1. Extract the folder.
2. Open `index.html` in a modern browser.
3. Select a demo role on the login screen.

## Demo roles

- Administrator
- Doctor
- Reception / Staff
- Patient

The demo stores only the selected role in browser localStorage. Data is fictional and kept in JavaScript memory for the current browser session.

## Included UI modules

- Role-based login experience
- Admin / Doctor / Staff / Patient navigation
- Dashboard KPIs
- Patients
- Doctors
- Departments
- Appointments
- Appointment booking and status updates
- Doctor schedule
- Check-in queue
- Prescriptions
- Medical reports
- Notifications
- Operational analytics
- Activity / audit logs
- System status
- Health endpoint representation

## Important

This is a frontend demonstration. It does not implement a real backend, PostgreSQL database, JWT authentication, password hashing, file storage, or production security. Those should be added as the backend/DevOps phase of the capstone.

All patient and medical information shown is fictional/sample data.
